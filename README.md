# DoseCare
DoseCare is a simple and responsive medication management system designed to help users organize their daily prescription medicines, track doses, monitor pill inventory, and stay consistent with their medication schedule.

## Key features

- 💊 Add and manage medicines
- ⏰ Daily dosage schedule
- ✓ Mark medicines as taken
- 📊 Track daily medication adherence
- 📦 Monitor remaining tablets
- ⚠️ Get low-stock refill alerts
- 🎉 Celebrate 100% daily compliance
- 📱 Responsive design for desktop and mobile
